# ChurchAI

ChurchAI is a modern, professional, and comprehensive church management application.

## Features Overview
- **Multi-tenant & Multi-campus:** Manage multiple churches and campuses.
- **Role-based Access:** Super Admin, Lead Pastor, Elder, Deacon, Member, Visitor, etc.
- **Member Management:** Registration, profiles, QR code scanning, family management, statistics.
- **Smart Calendar:** Services, events, rehearsals, sync with Google Calendar.
- **Digital Bible & AI Assistant:** AI-powered Bible study, sermon summarization, translations.
- **Multimedia:** Live streaming, podcasts, and media gallery.
- **Financial Management:** Tithes, offerings, donations with modern payment integrations.
- **Internal Social Network:** Chat, announcements, cell group management.

## Project Structure
- `backend/`: Node.js (Express + TypeScript) REST API, PostgreSQL schema.
- `web/`: Next.js web application for administration.
- `android/`: Native Android app using Kotlin and Jetpack Compose.
- `docs/`: Technical documentation and API specs.

## Architecture
- **Backend:** Node.js, Express, Prisma ORM, PostgreSQL.
- **Frontend (Web):** Next.js, React, TailwindCSS, Material UI concepts.
- **Mobile (Android):** MVVM, Clean Architecture, Jetpack Compose.
- **Security:** JWT authentication, RBAC (Role-Based Access Control).
